# skyline (가칭: 도트 미니 시티)

시티즈 스카이라인을 아주 단순하게 줄인 도트 스타일 도시 건설 게임입니다. 기획 중입니다.

방향(기획 전 메모):
- 무작위로 생성되는 작은 도트 땅에 건물 3개를 받아 놓고, 옆에 무엇이 있느냐로 점수를 얻는 점수형(Islanders 방식)
- 목표 점수를 채우면 다음 건물 묶음과 땅 확장, 못 채우면 끝 → 토스 랭킹으로 겨루기
- 맵·콘텐츠를 손으로 만들지 않고 규칙과 무작위로 끝없이 플레이

이름·로고·그림에 "Cities: Skylines"를 쓰지 않습니다(장르 구조만 참고).
