# skyline (가칭: 도트 미니 시티)

시티즈 스카이라인을 아주 단순하게 줄인 도트 스타일 도시 건설 게임입니다. 기획 중입니다.

방향(자세한 내용은 [게임 방향성](docs/GAME_DIRECTION.md)):
- 카이로소프트처럼 귀엽고 가벼운 도트 그림, 시티즈 스카이라인처럼 도로와 구역을 칠하면 도시가 스스로 자람
- 걸어 다니는 주민과 돈 팝업, 건물 3개·3칸 콤보와 도감, 마을 랭크로 해금과 땅 확장
- 한 판 10년, 끝나면 도시 점수로 토스 랭킹 경쟁. 땅과 이벤트가 무작위라 맵을 손으로 만들지 않음

이름·로고·그림에 "Cities: Skylines"를 쓰지 않습니다(장르 구조만 참고).
