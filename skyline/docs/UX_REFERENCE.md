# 조작(UX·UI) 참고 조사

2026-10-04. "도로 깔기·시설 배치가 불편하고, 하나 놓은 뒤에도 도구가 계속 선택돼 있어 다음 동작이 불편하다"는 피드백을 받고, 모바일 도시·마을 건설 게임이 터치 조작을 어떻게 처리하는지 조사했습니다.
카이로소프트의 조작 방식은 웹 자료가 적습니다. 확인하지 못한 내용은 **(미확인)** 으로 표시했습니다.

## 1. 지금 우리 게임의 문제

| 지금 | 왜 불편한가 |
|---|---|
| 도구(도로·주거·상업·공업·시설·철거)를 고르면 다른 도구를 고를 때까지 유지됨 | 시설 하나를 놓은 뒤에도 시설 모드라 다음 터치가 또 시설이 됨 |
| 도구가 켜져 있으면 한 손가락 끌기는 항상 "짓기" | 지도를 옮기려면 '보기'로 바꾸거나 두 손가락을 써야 함. 옮기려다 잘못 지어짐 |
| 도로는 끄는 즉시 깔리고 돈이 빠짐 | 미리보기도 없고 확정 단계도 없음. 손가락에 가려 끝점이 안 보임 |
| 시설은 손을 떼는 순간 지어짐 | 확인 단계가 없어서 위치를 잘못 잡으면 바로 손해 |
| 되돌리기는 1번, 같은 달 안에서만 됨 | 실수를 고치기 어려움 |
| 화면 가장자리로 끌어도 지도가 따라오지 않음 | 긴 도로를 한 번에 못 그림 |

## 2. 게임별 조사

### 포켓 시티 1·2 (Codebrew) — 가장 비슷한 게임
- **구성:** 우리와 같은 구성입니다(도로, 주거·상업·공업 구역, 전기·물, 공공시설, 철거). 세로 화면 한 손 조작이 됩니다. 2편은 터치 조작이 "거의 완벽하다"는 평을 받았습니다.
- **짓는 순서:** 짓기 → 분류 → 항목 → 손가락으로 끌어 배치합니다. 도로와 구역은 끌어서 칠합니다.
- **도구는 하나 지으면 꺼집니다.** 시설 하나를 놓으면 짓기 모드가 끝납니다. 같은 건물을 여러 개 놓고 싶을 때만 오른쪽 위 **"Multi"** 를 켭니다(2018년 업데이트로 추가).
- **받은 비판(그대로 체크리스트로 쓸 수 있음):**
  - 긴 도로를 그릴 때 지도가 손가락을 따라오지 않음
  - 메뉴가 매번 처음으로 돌아감(마지막 선택을 기억하지 않음)
  - 되돌리기 버튼이 없음

  - [Pocket Gamer 리뷰](https://www.pocketgamer.com/pocket-city/review/)

### 심시티 빌드잇 (EA)
- **도로:** 별도 모드에서 짓기·업그레이드·철거를 고릅니다. 짓기는 끌어서 선을 긋고, 도로가 겹치면 교차로가 자동으로 생깁니다. 철거는 직선으로 고른 뒤 ✓로 확정합니다.
- **건물:** 메뉴에서 지도로 끌어다 놓고 **✓를 눌러 확정**합니다. 공공시설은 놓는 동안 영향 범위가 초록색으로 보입니다.
- **옮기기:** 건물을 길게 누르면 옮기기 모드가 됩니다(무료). 보관함도 있습니다.
- **비판:** 탭하면 옆 건물이 잡히는 일이 잦고, 카메라 조작이 번거롭습니다.
- **개발자 강연:** "터치 조작은 수없이 반복해서 다듬어야 한다", "줄이고, 줄이고, 또 줄여라", "PC 관습을 버려라".
- 출처:
  - [EA 초보 가이드](https://help.ea.com/en/articles/simcity/simcity-buildit/beginner-guide/)
  - [LevelWinner 가이드](https://www.levelwinner.com/simcity-buildit-beginners-guide-tips-tricks-strategies/)
  - [해체 분석 글](https://ameetvadhia.wordpress.com/2016/05/30/simcitybuildit-deconstruction/)
  - [개발자 강연](https://www.slideshare.net/slideshow/designing-simcity-buildit-petri-ikonen/73387475)

### 카이로소프트 (Venture Towns, 던전 빌리지 2, 드림 타운 아일랜드)
- **배치:** 지도를 움직여서 건물 위치를 맞추고, 미세 조정은 건물을 길게 눌러서 합니다(던전 빌리지 2 가이드). 그래서 **건물 미리보기가 화면에 고정되고 지도가 그 밑에서 움직이는** 방식으로 보입니다. 이 방식이면 지도를 끄는 동작과 짓는 동작이 부딪히지 않습니다.
- **(미확인) 짓는 순서:** 메뉴 → 항목 → 미리보기 → 위치 맞추기 → 확인 버튼. 길·꽃처럼 1칸짜리는 연속으로 놓을 수 있습니다.
- **비판:** 칸이 작아서 원하지 않는 곳에 놓게 됩니다. 메뉴가 복잡하고 오래된 느낌입니다.
- **정리:** 그림과 분위기의 기준이지, 터치 조작의 모범은 아닙니다.
- 출처:
  - [던전 빌리지 2 가이드](https://www.levelwinner.com/dungeon-village-2-beginners-guide-tips-tricks-strategies-to-run-a-prosperous-town/)
  - [Venture Towns 리뷰](https://www.appspy.com/venture-towns/review/)
  - [드림 타운 아일랜드 리뷰](https://toucharcade.com/2023/06/27/dream-town-island-mobile-kairosoft-game-review-iphone-ipad-android/)

### TheoTown — 도트 그림 도시 게임
- **도로:** 시작 칸과 끝 칸을 차례로 탭합니다. 정확하지만 조금 느립니다.
- **구역:** 두 모서리를 탭하면 사각형으로 칠해집니다. "구역 둘레에 도로 자동 깔기" 옵션이 있습니다.
- **그 밖:** 시설을 놓을 때 영향 범위가 강조되고, 되돌리기 버튼과 격자 표시가 있습니다.
- 출처: [LevelWinner 가이드](https://www.levelwinner.com/theotown-beginners-guide-tips-tricks-strategies/)

### 미니 모터웨이 (Mini Motorways)
- **조작:** 한 손가락으로 끌면 도로가 그려지고, 두 손가락으로 지도를 옮깁니다. 지우기 전환 버튼과 되돌리기 버튼이 있습니다.
- **비판:**
  - 그리기와 지우기를 버튼으로 바꾸는 게 귀찮음
  - 지도를 옮기려다 도로를 지우거나 그리는 일이 생김
  - 손가락이 도로 끝을 가림
- 출처:
  - [Common Sense Media 리뷰](https://www.commonsensemedia.org/game-reviews/mini-motorways)
  - [Nook Gaming 리뷰](https://www.nookgaming.com/mini-motorways-review/)

### 타운스케이퍼 (Townscaper)
- **조작:** 탭하면 짓고, 길게 눌렀다 떼면 지웁니다. 되돌리기·다시하기 버튼이 항상 보이고, 지을 때 진동이 옵니다. 세로 화면 한 손 조작이 됩니다.
- **정리:** 조작 종류가 가장 적은 예입니다.
- 출처: [TapSmart 리뷰](https://www.tapsmart.com/news/townscaper-review/)

### 아일랜더스 모바일 (Islanders: Mobile, 2025) — 나쁜 예
- **비판:**
  - 건물을 한 번 누르면 정보가 나오고, 한 번 더 눌러야 배치가 시작됨
  - 실수로 배치되거나 선택이 풀림
  - 회전이 오래 걸림
- **사용자 요청:** 메뉴에서 바로 끌어다 놓기, 정보는 길게 눌러서 보기.
- 출처: [App Store 리뷰](https://apps.apple.com/us/app/islanders-mobile/id6745312000)

### 디자이너 시티 (Designer City)
- **조작:**
  - "+" → 고르기 → 원하는 곳으로 옮기기
  - 두 번 탭 → 옮기기
  - 탭 → 휴지통
- **철거:** 여러 개를 골라 한 번에 철거할 수 있고, 구역 단위 철거도 됩니다.
- 출처: [FAQ](https://spheregamestudios.com/games/designercity/FAQ.htm)

### 헤이데이 / 타운십 / 클래시 오브 클랜 — "편집 모드"와 ✓/✗
- **헤이데이:** 편집 버튼으로 편집 모드에 들어갑니다. 길게 눌러 잡고 끌어 옮긴 뒤 ✓(저장) 또는 ✗(취소)를 누릅니다.
- **타운십:** 길게 눌러 옮기고, 초록 버튼으로 확정합니다. 보관함이 있습니다.
- **(미확인) 클래시 오브 클랜:**
  - 새 건물 위에 ✓/✗가 떠 있고, 놓을 수 있으면 바닥이 초록, 못 놓으면 빨강으로 표시됨
  - 건물을 끌면 건물이 움직이고, 다른 곳을 끌면 지도가 움직임
  - 성벽은 하나를 확정하면 옆에 다음 성벽이 자동으로 준비됨
- 출처:
  - [Hay Day Wiki 편집 모드](https://hayday.fandom.com/wiki/Edit_Mode)
  - [Township 도움말](https://playrix.helpshift.com/hc/en/3-township/faq/15058-how-do-i-rearrange-the-buildings-in-my-town/)

## 3. 잘 만든 게임들의 공통점

1. **지도 옮기기와 짓기는 "어디서 끌기 시작했나"로 나눕니다.**
   - 미리보기 건물을 끌면 건물이 움직이고, 빈 땅을 끌면 지도가 움직입니다.
   - 도로·구역 칠하기는 한 손가락이 칠하기, 두 손가락이 이동입니다.
   - 칠하기 도구가 아닌데 한 손가락 끌기로 무언가 지어지는 일은 없어야 합니다.
2. **건물은 두 단계로 확정합니다.** 미리보기(초록/빨강 바닥, 가격 표시) → ✓/✗. 잘못 놓는 일이 없어집니다.
3. **도구가 계속 켜져 있을지는 종류마다 다릅니다.**
   - 발전소·경찰서 같은 시설: 하나 놓으면 기본 모드로 돌아갑니다(포켓 시티).
   - 도로·구역·나무처럼 반복하는 것: 계속 켜 두되, 큰 "완료" 버튼을 보여 줍니다.
4. **도로는 끌어서 그리되, 손을 떼기 전까지는 미리보기만 보여 줍니다.**
   - 손가락 위쪽에 가격을 띄웁니다.
   - 화면 가장자리에서는 지도가 자동으로 따라옵니다.
   - 꺾임이 한 번인 ㄱ자 미리보기가 흔합니다(일반적인 방식, 출처 확인 안 됨).
5. **구역은 사각형으로 끌어서 칠합니다.** 구역 둘레 도로를 자동으로 까는 옵션도 있습니다(TheoTown).
6. **되돌리기 버튼은 기본입니다.** 없으면 비판받습니다(포켓 시티).
7. **철거는 범위를 고른 뒤 ✓로 확정합니다.** 건물 하나는 탭하면 작은 말풍선에 [옮기기·철거]가 나옵니다.
8. **시설을 놓는 동안 영향 범위를 보여 줍니다.**
9. **메뉴는 2~3번 탭이면 됩니다.**
   - 마지막에 고른 분류·항목을 기억합니다.
   - 메뉴에서 지도로 바로 끌어다 놓을 수 있게 합니다.
   - 세로 화면에서는 주요 버튼을 엄지가 닿는 아래쪽에 둡니다.
10. **놓을 때 진동·소리·초록/빨강으로 바로 알려 줍니다.**

## 4. 주 참고작 추천

1. **포켓 시티 1·2:** 게임 구성이 같고 세로 화면입니다. "도구가 계속 켜져 있는 문제"를 이미 풀었습니다(하나 놓으면 꺼짐 + Multi). 받은 비판(자동 따라가기 없음, 메뉴가 처음으로 돌아감, 되돌리기 없음)은 그대로 피하면 됩니다.
2. **심시티 빌드잇:** 도로·구역·철거를 하위 모드로 나누는 방식, 미리보기 + ✓, 길게 눌러 옮기기, 영향 범위 표시를 참고합니다.
3. **카이로소프트 + 클래시 오브 클랜의 ✓/✗:** 분위기는 카이로소프트, 확정 버튼은 클래시 방식을 따릅니다.

(4순위: TheoTown — 도트 그림, 두 모서리 구역, 영향 범위, 되돌리기)

## 5. 우리 게임에 맞춘 제안 (아직 안 함, 확인 필요)

| 무엇 | 지금 | 바꾸는 안 |
|---|---|---|
| 시설 | 손을 떼면 바로 지어짐, 시설 모드 유지 | 미리보기 + ✓/✗(엄지 근처) → 확정하면 '보기'로 돌아감. 빈 땅을 끌면 지도 이동, 미리보기를 끌면 위치 이동 |
| 도로 | 끄는 즉시 깔리고 돈이 빠짐 | 끄는 동안 미리보기(ㄱ자, 가격 표시) → 손 떼면 확정. 가장자리 자동 따라가기. 도구 유지 + "완료" 버튼 |
| 구역 | 사각형 칠하기(지금도 괜찮음) | 그대로 두고 "완료" 버튼과 두 손가락 이동만 확실히 |
| 철거 | 사각형 → 손 떼면 바로 철거 | 사각형 → ✓로 확정. 건물을 탭하면 말풍선에 [철거] |
| 기본 모드('보기') | 탭하면 정보 | 탭하면 정보 + [철거] 말풍선 |
| 되돌리기 | 1번, 같은 달만 | 여러 번(예: 10번), 달이 바뀌어도 되게 |
| 메뉴 | 오른쪽 세로 도구 + 아래 시설 띠 | 마지막 고른 시설을 기억(지금도 기억함). 버튼을 아래 엄지 영역으로 옮길지는 따로 결정 |
