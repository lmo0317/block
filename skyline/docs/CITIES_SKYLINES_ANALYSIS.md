# 시티즈: 스카이라인 분석

2026-10-02 작성. *Cities: Skylines*(2015, Colossal Order / Paradox)와 후속작 *Cities: Skylines II*(2023)를 분석하고, 우리 게임에 가져올 것과 버릴 것을 정리합니다. 확인하지 못한 내용은 [불확실]로 표시합니다.

## 1. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 장르 | 도시 건설 시뮬레이션 (샌드박스) |
| 플랫폼 | PC 중심, 이후 콘솔·스위치 |
| 판매 | 출시 24시간 25만 장, 한 달 100만 장, 2022년 6월까지 1,200만 장 |
| 평가 | Metacritic PC 85점 (스위치 67점) |
| 핵심 | 시민과 차량을 하나하나 시뮬레이션하는 교통, 모드(Steam Workshop) |

## 2. 기본 순환

**도로를 깐다 → 구역을 칠한다 → 전기·수도·하수를 잇는다 → 인구가 늘어 마일스톤 달성 → 새 시설 해금 → 교통·오염·예산 문제 해결 → 다시 확장**

플레이어는 건물을 하나하나 짓지 않습니다. 구역만 정해 주면 수요에 따라 건물이 저절로 지어지고 자랍니다. 플레이어는 **조건을 만들어 주는 사람**입니다.

## 3. 시스템별 정리

### 3-1. 구역 (Zoning)
- 주거(저밀도·고밀도), 상업(저밀도·고밀도), 산업, 오피스.
  - 산업은 상품을 만들지만 오염을 냅니다.
  - 오피스는 일자리만 만들고 오염이 없습니다.
- 건물은 **레벨 1~5**로 성장합니다.
  - 주거: 지가와 주민 교육 수준
  - 상업: 지가와 손님의 부유함
  - 산업·오피스: 노동자 교육과 서비스 범위
- 구역은 도로를 따라 칸 단위로 칠합니다. 도로가 곡선이어도 칸이 맞춰집니다.

### 3-2. 수요 미터 (RCI)
주거·상업·산업 수요를 막대 3개로 보여 줍니다. 무엇을 더 칠해야 할지 알려 주는 **가장 중요한 안내판**입니다.
- 주거 수요: 집이 필요한 정도
- 상업 수요: 시민 대비 노동자 비율, 여가 기회
- 산업 수요: 실업률

### 3-3. 도로와 교통 — 이 게임의 심장
- 시민과 차량 하나하나가 출발지에서 목적지까지 길을 찾아 이동합니다.
- **교통이 핵심인 이유:** 쓰레기차·소방차·영구차와 화물 트럭이 막히면 서비스가 끊깁니다. 그러면 건물이 버려지고, 산업이 무너지는 연쇄가 일어납니다.
- 기본 게임은 교통을 다룰 도구가 부족해서, 신호·차선을 조절하는 모드(Traffic Manager)가 사실상 필수가 됐습니다.

### 3-4. 기반시설과 공공 서비스
- 처음부터: 전기, 상수도, 하수도. 파이프·전선망을 연결해야 합니다.
- 마일스톤으로 해금: 교육, 쓰레기, 의료(장례 포함) → 경찰, 소방
- 서비스는 건물마다 **영향 범위**가 있습니다. 범위 안의 건물만 혜택을 받습니다.

### 3-5. 지가·오염·소음
- **지가를 올림:** 서비스 범위, 공원·광장(가장 효과적), 물가
- **지가를 내림:** 땅·물 오염, 늦은 서비스, 소음(큰 도로·지하철역 주변)
- 지가가 높아야 고레벨 건물이 들어서고, 너무 낮으면 건물이 버려집니다.

### 3-6. 예산·세금·대출
- 세율은 구역별로 1~29%이고 기본 9%입니다. 13~14%를 오래 넘기면 시위가 일어나고 수요가 떨어집니다.
- 서비스 예산은 50~150%로 조절하고, 낮과 밤을 따로 정합니다.
- 대출은 3단계(₡20,000 / ₡60,000 / ₡200,000)이고, 이자는 5~15%입니다.

### 3-7. 지구와 정책
- 붓으로 칠해 지구를 나누고, 지구마다 정책을 겁니다.
  - 고층 금지
  - 화물차 통과 금지
  - 자전거 장려
  - 산업 폐수 정화 (유지비가 듦)
- 산업 특화(임업·농업·광업·석유)와 상업 특화(관광·레저)가 있습니다.

### 3-8. 마일스톤 (인구 단계)

| 단계 | 인구 | 해금 |
|---|---|---|
| Little Hamlet | 120~500 | 교육·쓰레기·의료, 세금·대출 |
| Worthy Village | 240~1,000 | 경찰·소방, 지구·정책 |
| Boom Town | 650~2,800 | 버스·트램·페리 |
| Big Town | 1,800~8,000 | 지하철, 고밀도, 오피스 |
| Small City | 2,600~11,000 | 기차·모노레일 |
| Capital City~ | 8,000~36,000+ | 선박·항공 |
| Megalopolis | 20,000~90,000 | 모뉴먼트 |

- 인구 수치는 패치마다 달라서 범위로 적었습니다.
- 단계마다 **땅(2×2km 타일)을 더 살 수 있게** 됩니다. 확장이 곧 보상입니다.

### 3-9. 특별 건물과 모뉴먼트
- **유니크 빌딩:** 업적처럼 조건을 채우면 열립니다. 예: 세율을 5% 미만으로 유지.
- **모뉴먼트:** 마지막 마일스톤, 특정 유니크 빌딩 6종, 땅 9칸 확보 등 조건이 높습니다. 도시 전체에 큰 효과를 줍니다.
  - 핵융합 발전소: 청정 전력 16,000MW
  - 하드론 충돌기: 도시 전체 교육을 담당
- 장기 목표이자 자랑거리 역할을 합니다.

### 3-10. 대중교통·지형
- 버스, 트램, 지하철, 기차, 페리, 항공이 있습니다. 개발사 전작이 교통 게임(Cities in Motion)입니다.
- 강·바다는 지가를 올리지만, 상수와 하수 위치 문제를 만듭니다.

## 4. 재미 요소

| 재미 | 설명 |
|---|---|
| 창작 | 내가 그린 도로와 구역대로 도시가 생겨나는 샌드박스 |
| 구경 | 차와 사람이 실제로 돌아다니며 도시가 **살아 움직이는** 모습 |
| 문제 해결 | 막힌 교통을 뚫는 퍼즐. "가장 어렵고 답답하지만 엄청 만족스럽다"(PC Gamer) |
| 성장 | 마을이 대도시가 되고 땅이 넓어지는 단계적 보상 |
| 모드 | 하루 1,000개 이상 올라오는 사용자 콘텐츠 |

## 5. 어려운 점·비판

- **교통 관리가 너무 어렵고 손이 많이 갑니다.** 기본 게임엔 도구가 부족해 모드에 의존합니다.
- **데스웨이브:** 한꺼번에 입주한 같은 나이 시민이 비슷한 시기에 한꺼번에 사망합니다. 그러면 영구차가 부족해지고 건물 방치가 연쇄로 일어납니다.
- **복잡함:** 세율, 예산, 정책, 기반시설망이 얽혀 진입 장벽이 높습니다.
- **후반 성능 저하:** 도시가 커질수록 느려집니다.
- **끝이 없음:** 목표가 약해서 스스로 목표를 세워야 재미있습니다.

## 6. 후속작(Cities: Skylines II)이 주는 교훈

- **바뀐 점**
  - 맵이 더 커졌습니다.
  - 교통 AI가 비용과 쾌적함까지 따집니다.
  - 인구 대신 **경험치(XP)로 마일스톤 20개**를 엽니다. 건설과 행복도로 경험치가 쌓입니다.
  - 마일스톤 보상으로 땅 확장 허가와 기술 포인트를 줍니다.
- **출시 실패**
  - 성능 문제가 컸습니다(Metacritic 유저 점수 3.7).
  - 월세 경고 팝업이 화면을 덮었습니다.
  - 경제가 너무 쉽다는 지적이 있었습니다.
  - DLC는 환불 사태까지 겪었고, 결국 개발사가 교체됐습니다(2025년 11월).
- **교훈**
  - **시뮬레이션 깊이보다 성능과 피드백이 먼저입니다.**
  - **경고·팝업이 화면을 덮으면 안 됩니다.**
  - **"돈 걱정 없는 경제"는 재미를 죽입니다.**

## 7. SimCity(2013)보다 성공한 이유

- **SimCity(2013)의 실패:**
  - 혼자 해도 상시 온라인이 필요했고, 출시 직후 서버가 무너졌습니다.
  - 도시가 너무 작았습니다.
  - 모드를 금지했습니다.
- **Cities: Skylines의 대응:** "오프라인 플레이", 큰 맵, 모드 지원을 정면으로 내세웠습니다.
- **교훈:** 플레이어가 원하는 것(큰 도시, 자유)을 막지 말고, 불편을 주는 정책은 피해야 합니다.

## 8. 모바일·단순화 계열

| 게임 | 단순화 방식 | 수익 모델 |
|---|---|---|
| Pocket City | 도로 옆 구역, 시설, 재정만 남긴 모바일 SimCity | 유료 $4.99 (무료판은 보상형 광고) |
| SimCity BuildIt | 공장 타이머로 자재를 모아 건물을 업그레이드 | 부분 유료. 과금 유도 비판(Metacritic 58) |
| Islanders | 건물 배치 위치로 점수를 얻는 퍼즐, 기준 점수를 넘으면 새 섬 | 유료 |
| Mini Motorways | 같은 색 집과 건물을 도로로 잇는 교통 퍼즐 | 모바일은 Apple Arcade |
| Townscaper | 목표 없는 장난감. 찍으면 집 모양이 자동으로 변함 | 유료 |

## 9. 우리 게임에 주는 시사점

| 원작 요소 | 판단 | 이유 |
|---|---|---|
| 구역을 칠하면 건물이 **저절로** 지어지고 자람 | **가져감** | 적은 조작으로 도시가 살아나는 핵심 재미 |
| 수요 막대(RCI) | **가져감 (단순화)** | 다음에 할 일을 알려 주는 안내판 |
| 서비스 **영향 범위** | **가져감** | 칸 위의 거리 퍼즐로 이해하기 쉬움 |
| 지가(공원·물가 +, 공장·소음 −) | **가져감** | 배치 고민의 핵심. 카이로소프트 콤보와 잘 맞음 |
| 인구 단계 → 해금 + **땅 확장** | **가져감** | 단계적 보상 |
| 특별 건물·모뉴먼트 | **가져감 (몇 개만)** | 장기 목표와 자랑거리 |
| 시민 하나하나의 **교통 시뮬레이션** | **버림** | 가장 어렵고 무겁고 손이 많이 감. 차는 **보여 주기용**으로만 |
| 전기·수도·하수 배관망 | **버림 → 범위형으로** | 망 연결 대신 "발전소 범위 안이면 OK" |
| 세율 구역별 1~29%, 예산 슬라이더, 대출 3단계 | **크게 단순화** | 세율 3단계 정도만 |
| 지구·정책 | **버림 (후반 카드 선택으로 대체 가능)** | 복잡도 대비 재미가 낮음 |
| 끝없는 샌드박스 | **바꿈** | 정해진 기간 후 점수 → 랭킹 (카이로소프트 방식) |
| 데스웨이브 같은 숨은 연쇄 실패 | **피함** | 원인이 안 보이는 실패는 캐주얼 게임에서 좌절만 줌 |
