# 아트 가이드 — 도트 미니 시티

아트 디렉터 스킬(`art-director`)이 그림을 만들기 전에 읽는 기준입니다. 바뀌면 여기부터 고칩니다.

## 스타일 한 줄

**카이로소프트 경영 게임 같은 쿼터뷰(아이소메트릭) 도트.** 진짜 저해상도 픽셀(색 수 적음, 1px 진한 외곽선)을 화면에서 2배로 크게 보여 줍니다.

바뀐 순서(사용자 요청): 16px 위에서 본 코드 도트 → Codex 정면 일러스트풍 → **2026-10-02 쿼터뷰 도트**("카이로처럼 isolate 뷰, 픽셀 아트 도트 스타일로 이쁘게").

## 크기와 시점

- 맵 칸: **64×32 마름모**(2:1 아이소메트릭). 셀 (x, y)의 중심 = ((x − y)·32, (x + y)·16). x는 화면 오른쪽 아래, y는 왼쪽 아래로 늘어남
- 화면 배율: 기본 **2배**(칸 하나 약 128px, 가로 5~6칸 보임), 1~4배 정수만. 필터는 nearest(흐리게 하지 않음)
- 건물: 가로 64px(한 칸), 세로는 그림 비율대로. 그림 아래 끝이 칸의 아래 꼭짓점에 닿게 그림. 뒤 줄부터 앞 줄 순서로 그려서 앞 건물이 뒤 건물을 가림
- 주민 세로 18px, 차 가로 30px(앞모습·뒷모습 2장, 좌우 뒤집기로 4방향), 도구 아이콘 26px(버튼에서 2배), 동전 12px, 경고 말풍선 16px

## 규칙

- 외곽선 1px 진한 남보라(#281E2E), 빛은 왼쪽 위, 밝고 따뜻한 색
- 투명 배경, 땅·그림자·글자·로고 없음. 간판은 글자 대신 그림
- 주거·상업·공업은 빈 땅(울타리 잔디·보도블록·노란 줄 자갈), 공사장, 건물 모두 한눈에 구별
- 시설(경찰·소방·병원·학교)은 평지붕·상징물로 주택과 확실히 다르게
- 게임 안 그림은 차분하게. 큰 일러스트는 타이틀 액자 안에만

## 만드는 방법

| 종류 | 방법 | 위치 |
|---|---|---|
| 건물·시설·공사장·나무·주민·차·아이콘·말풍선 | Codex 생성 → `tools/pixelize.py`로 진짜 도트 변환 (`tools/codex_art.py`, 프롬프트는 `ASSETS`) | 원본 `art/raw/`(git 제외), 게임용 `assets/sprites/px/` |
| 풀·물(물가 모래 16종×2프레임)·도로 16종·다리·빈 구역 | 코드로 픽셀 계산 (`tools/generate_ground.py`) | `assets/sprites/px/` |
| 차 색 4가지, 앱 아이콘 | 코드 (같은 스크립트) | 〃 |
| 속도 버튼, 실행 취소·도감·메뉴 아이콘, 불꽃 | 옛 코드 도트 | `tools/generate_sprites.py` → atlas |
| 타이틀 일러스트 | Gemini | `art/concept_keyart_b.png` → `assets/art/title.jpg` |

기준 그림: `art/style_ref.png`(쿼터뷰 빨간 지붕 집). Codex 생성 때마다 붙입니다.
새 그림: `ASSETS`에 한 줄 → `python tools/codex_art.py --gen <이름>` → 검수 시트 → 게임에서 `Art.tex(이름)`.
도트 변환만 다시: `python tools/codex_art.py --fit all`.
