# 아트 가이드 — 도트 미니 시티

아트 디렉터 스킬(`art-director`)이 그림을 만들기 전에 읽는 기준입니다. 바뀌면 여기부터 고칩니다.

## 스타일 한 줄

**카이로소프트 풍 도트 + 위에서 내려다보는 3/4 시점**(정사각형 칸, 건물은 정면 벽과 지붕이 보임). 진짜 저해상도 픽셀(색 수 적음, 1px 진한 외곽선)을 화면에서 2배로 크게 보여 줍니다.

바뀐 순서(사용자 요청): 16px 코드 도트 → Codex 정면 일러스트풍("구림") → 쿼터뷰 도트("너무 가려서 못 씀") → **2026-10-02 3/4 시점 카이로 풍 도트**.
남의 게임 그림(스타듀밸리, 팬게임 포함)은 저작권 때문에 쓰지 않습니다. 스타일만 참고합니다.

## 크기와 시점

- 맵 칸: **48×48**. 셀 (x, y)의 왼쪽 위 = (x·48, y·48)
- 화면 배율: 기본 **2배**(칸 96px, 가로 약 7칸), 1~4배 정수만. 필터는 nearest
- **그림은 2배 해상도로 저장하고 절반 크기로 그림**(`MapView.DETAIL`). 기본 2배 확대에서 그림 1픽셀 = 화면 1픽셀. 48px로 줄였더니 "허접하다"는 피드백(2026-10-03)
- 건물: 가로 96px(한 칸), 세로는 그림 비율대로. 그림 아래 끝이 칸 아래에 닿고 윗칸으로 솟음. 위 줄부터 아래 줄 순서로 그림
- 땅 타일 96×96, 주민·차 세로 32px(옆·앞·뒷모습, 옆모습은 좌우 뒤집기), 도구 아이콘 52px, 동전 24px, 경고 말풍선 32px

## 규칙

- 1px 진한 외곽선(#281E2E), 빛은 왼쪽 위, 밝고 귀여운 색
- 투명 배경, 땅·그림자·글자·로고 없음. 간판은 글자 대신 그림
- 주거·상업·공업은 빈 땅(울타리 잔디·보도블록·노란 줄 자갈), 공사장, 건물 모두 한눈에 구별
- 시설(경찰·소방·병원·학교)은 평지붕·상징물로 주택과 확실히 다르게
- 게임 안 그림은 차분하게. 큰 일러스트는 타이틀 액자 안에만

## 만드는 방법

| 종류 | 방법 | 위치 |
|---|---|---|
| 건물·시설·공사장·나무·주민·차·아이콘·말풍선 | Codex 생성 → `tools/pixelize.py`로 진짜 도트 변환 (`tools/codex_art.py`, 프롬프트는 `ASSETS`) | 원본 `art/raw/`(git 제외), 게임용 `assets/sprites/px/` |
| 풀·물(물가 모래 16종×2프레임)·도로 16종·다리·빈 구역 | 코드로 픽셀 계산 (`tools/generate_ground.py`) | `assets/sprites/px/` |
| 차 색 4가지, 앱 아이콘 | 코드 (같은 스크립트) | 〃 |
| 속도 버튼, 실행 취소·메뉴 아이콘, 불꽃 | 옛 코드 도트 | `tools/generate_sprites.py` → atlas |
| 타이틀 일러스트 | Gemini | `art/concept_keyart_b.png` → `assets/art/title.jpg` |

기준 그림: `art/style_ref.png`(빨간 지붕 집). Codex 생성 때마다 붙입니다.
새 그림: `ASSETS`에 한 줄 → `python tools/codex_art.py --gen <이름>` → 검수 시트 → 게임에서 `Art.tex(이름)`.
도트 변환만 다시: `python tools/codex_art.py --fit all`.
