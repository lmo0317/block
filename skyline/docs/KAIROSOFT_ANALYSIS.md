# 카이로소프트 게임 분석

2026-10-02 작성. 일본의 소규모 개발사 카이로소프트(Kairosoft)의 게임 공식을 정리합니다. 특히 그들이 직접 만든 도시 건설 게임 **Venture Towns**를 자세히 봅니다. 확인하지 못한 내용은 [불확실], 직접 관찰에 근거한 통념은 [일반지식]으로 표시합니다.

## 1. 회사 개요

- 1996년 설립, 직원 14명의 작은 회사(도쿄 니시신주쿠)입니다. 일본 피처폰 게임에서 출발했습니다.
- 2010년 iOS판 **Game Dev Story**가 첫 주에 iPhone 매출 Top 10에 들었습니다.
- Pocket Gamer는 카이로소프트 게임들을 **"그 자체로 하나의 장르"**라고 평했습니다. 주제만 바꿔 같은 공식을 수십 편에 적용합니다.

## 2. 공통 공식

| 요소 | 내용 | 예 |
|---|---|---|
| 작은 칸 맵 | 한 화면 남짓한 도트 맵에 시설을 놓음 | 모든 작품 |
| 걸어 다니는 손님 | 손님·주민이 직접 돌아다니며 돈을 씀. **구경하는 재미** | 온천, 쇼핑몰, 학교 |
| **콤보** | 특정 시설 2~3개를 가까이 두면 평판·가격·품질 보너스 | Mega Mall Story 같은 층 3매장, Game Dev Story 장르×타입 궁합 |
| 스팟 | 특정 위치에 놓으면 받는 입지 보너스 | Pocket Academy |
| 연구 포인트 | 시설·직원이 포인트를 만들고, 그걸로 새 시설이나 이벤트를 엶 | Game Dev Story Research Data, Venture Towns 연구 4종 |
| 직원·캐릭터 성장 | 훈련, 레벨업, 전직 | Game Dev Story, Dungeon Village |
| 랭크 → 해금 | 조건을 채우면 등급이 오르고 건물·이벤트가 열림 | Pocket Academy 6단계, Dungeon Village 별 5개 |
| 연례 행사 | 매년 정해진 달에 시상식·축제·대회 | Game Dev Story 12월 시상식 |
| 정해진 기간 → 점수 | N년 뒤 점수를 매겨 온라인 랭킹. 그 뒤에도 계속 가능 | Game Dev Story 20년, Venture Towns 15년 |
| 이어받기 | 새 게임에서 발견한 조합·일부 요소를 이어받음 | Game Dev Story 장르·타입, Venture Towns 콤보 정보 |
| 경기 변동·이벤트 | 호황·불황, 복권 당첨 같은 무작위 사건 | Hot Springs Story 경기 5단계 |
| Fever | 인기도가 최대가 되면 특별 이벤트 | Mega Mall Story |

## 3. 작품별 예시

- **Game Dev Story**
  - 장르와 타입의 궁합(RPG+판타지 등)이 콤보 역할을 합니다.
  - 리뷰 합계 32점 이상이면 명예의 전당에 오릅니다.
  - 20년 뒤 총자산이 점수가 됩니다. Metacritic 86점입니다.
- **Pocket Academy**
  - 학교 랭크 6단계마다 건물이 열립니다.
  - 동아리, 대회, 축제가 있습니다.
- **Hot Springs Story**
  - 시설을 늘려 부자 손님과 가이드북 기자를 부릅니다.
  - 경기가 5단계로 바뀌고, 손님마다 인내심이 다릅니다.
  - Metacritic 83점입니다. "게임이 혼자 굴러간다"는 비판도 있었습니다.
- **Mega Mall Story**
  - 층마다 맞는 업종이 있고, 같은 층 매장 3개 조합으로 콤보가 납니다.
  - 인기 100에서 Fever가 일어납니다.
- **Dungeon Village**
  - 모험가 25명이 알아서 싸우고 마을 가게를 이용합니다.
  - 마을 랭크가 별 1~5개로 오릅니다.

## 4. Venture Towns 자세히 (카이로소프트의 도시 건설)

- 원제는 財閥タウンズV입니다. iOS 2011, Android 2012, 스위치 2018, Steam 2022. Steam 평가는 대체로 긍정(74%)입니다.

### 건물
- 주택(빈 건물 → 성까지 단계), 오피스(S·M·L), 환경(길·포장·조경), 상점·식당·오락시설이 있습니다.
- 건물마다 건설비, 유지비, 연구 포인트, 주민 능력치 효과가 있습니다.

### 주민 — 돈의 흐름 자체
- 오피스에서 월급을 받아 상점에서 쓰고, 매년 3월에 집세를 냅니다.
- 동선은 **"집 → 목적지 1곳 → 집"**뿐입니다. 이동 범위가 정해져 있고, 자전거나 차를 사면 넓어집니다. 교통 체증은 없습니다.
- 저축이 쌓이면 집을 업그레이드합니다. 회사 돈으로 전직하면 전문직이 되고, 새 업종이 열립니다.
- 반려동물이 능력치를 올립니다: 개는 근무, 고양이는 매력, 오리는 지능.
- 주민은 약 25명 규모입니다. 숫자가 작아서 한 명 한 명이 눈에 들어옵니다.

### 콤보
- **특정 건물 3개가 서로 3칸 안에 있으면** 성립하고, 겹치면 효과도 쌓입니다.

| 콤보 | 건물 | 지가 | 상품가 |
|---|---|---|---|
| Gourmet | 초밥집 + 중식당 + 바 | +20% | +20% |
| Business | 오피스 + 오피스 + 시티호텔 | +35% | +30% |
| Star | 맨션 + 부티크 + 백화점 | +50% | +50% |

### 타운 랭크
- 단계: Village → Burg → Town → Super Town → Venture Town
- 조건은 숫자로 명확합니다. 예: Super Town = 주민 16명 이상 + 전문직 5명 + 콤보 6개.
- 마지막 단계에는 **전국 랭킹 8위 이내**가 들어갑니다.

### 연구·이벤트
- 상점에서 연구 포인트 4종(음식·오락·서비스·문화)이 나옵니다.
- 이 포인트로 한시 이벤트를 엽니다. 예:
  - 새 관찰회: 이동 범위 증가
  - 경제 정상회의: 지가 상승
  - UFO 심포지엄: 능력치 상승

### 끝과 점수
- 15년차 4월에 점수를 계산해 온라인 랭킹에 올립니다.
  - 점수 항목: 자금, 주민 수×1000, 타운 규모×7000, 콤보×6 등
- 그 뒤에도 계속할 수 있고, 빠른 속도가 해금됩니다.
- 새 게임에는 첫 주민과 콤보 정보를 이어받습니다.

### 비판
- 같은 공식의 재탕이라는 지적이 있습니다.
- **쇼핑하는 모습이 화면에 안 보여서 반응이 약합니다.**
- 초반에 빨리 감기가 없어 기다림이 지루합니다.

[불확실] 땅을 넓히는 방식과 철도 유무는 확인하지 못했습니다. 철도는 Station Manager의 핵심 시스템입니다.

### 관련작
- **Dream Town Story** (부분 유료): Venture Towns의 정신적 후속작입니다.
  - 버스정류장과 지하철이 있습니다.
  - 주민끼리 결혼합니다.
  - 마을이 커지면 지역이 열립니다.
- **Dream Town Island:** 2개 조합 콤보가 **171종**입니다. 조합 도감 수집이 곧 콘텐츠입니다.
- **Station Manager:** 역 주변에 상점을 지어 승객을 모으고 노선을 엽니다.

## 5. 그림·화면·속도

- **그림** [확인]: 위에서 보거나 살짝 기운 시점의 작은 도트 맵에, 2~3등신 캐릭터가 돌아다닙니다. 마스코트는 카이로봇입니다.
- **화면 구성** [일반지식]
  - 세로 화면 대부분을 맵이 차지합니다.
  - 위에는 자금과 날짜, 아래에는 메뉴 버튼이 한 줄로 있습니다.
  - 메뉴는 테두리 있는 RPG풍 목록 창입니다.
- **피드백** [일반지식]: 돈과 포인트가 캐릭터 머리 위에 숫자로 튀어 오릅니다.
- **속도:** 게임 속 1년이 몇 분 만에 지나갑니다 [일반지식]. 빠른 속도는 엔딩 후 해금되거나 유료로 팝니다.

## 6. 수익 모델의 변화

| 시기 | 방식 | 반응 |
|---|---|---|
| 초기 | **유료 앱** (예: Venture Towns $5.99) | "값어치를 한다" |
| 2012 실험 | 광고 포함 무료(하단 배너, $3.99에 광고 제거) | "플레이어를 벌하지 않는 무료" 호평 |
| 이후 | **부분 유료**: 다이아·티켓·패스 판매, 일부는 유료 DX판 별도 | 스태미나·대기시간·광고 룰렛에 불만. "무료판도 사실상 풀게임"이라는 호평도 |

## 7. 시티즈 스카이라인보다 캐주얼한 이유

| | 시티즈 스카이라인 | 카이로소프트 |
|---|---|---|
| 이동 | 시민 하나하나 길 찾기, 교통 체증이 핵심 난제 | "집 → 목적지 → 집", 이동 범위 숫자만 제약 |
| 기반시설 | 전기·상하수 배관망, 오염 확산 | 없음 |
| 숫자 규모 | 시민 수만~수십만, 세율·예산·대출 | 주민 약 25명, 콤보는 "3개·3칸·고정 %" |
| 목표 | 끝없는 샌드박스, 인구 마일스톤 | 랭크 조건이 숫자로 명확, 15~20년 후 점수 |
| 재미의 중심 | 창작과 문제 해결 | **조합 발견과 수집**, 귀여운 구경 |
| 피드백 | 정보 창과 그래프 | 돈 숫자 팝업, Fever 연출 |

## 8. 우리 게임에 주는 시사점

- **가져갈 것**
  - 콤보(3개·3칸) + 콤보 도감
  - 숫자로 명확한 랭크와 해금
  - 정해진 기간 후 점수와 온라인 랭킹
  - 새 판으로의 이어받기
  - 걸어 다니는 주민과 머리 위 돈 팝업
  - 연례 행사와 무작위 이벤트
  - 작은 숫자
- **고칠 것**
  - **소비 장면을 화면에 보여 주기:** 상점에 들어가면 동전이 튀는 식으로. Venture Towns가 비판받은 지점입니다.
  - 초반부터 빨리 감기 제공
  - "혼자 굴러가는" 느낌을 막기 위해 플레이어가 고를 일을 자주 주기
- **피할 것:** 스태미나, 대기시간, 광고 룰렛처럼 플레이를 막는 과금. 랭킹 경쟁 게임이라 점수에 영향을 주는 결제는 공정성을 해칩니다.
