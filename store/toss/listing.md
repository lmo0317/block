# 앱인토스 등록 정보 — 퍼즐블록

콘솔 입력란에 그대로 넣을 수 있게 정리했습니다. 이미지는 같은 폴더에 있습니다(`python tools/generate_store_assets.py --toss <캡처 폴더>`로 다시 만들 수 있음).

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 한국어 앱 이름 | 퍼즐블록 |
| 영어 앱 이름 | PuzzleBlock |
| 부제 | 빈자리에 딱 맞춰 줄을 터뜨려요 |
| appName | `puzzleblock` (변경 불가, `toss/apps-in-toss.config.ts`와 같아야 함) |
| 앱 유형 | 게임 |

### 상세 설명

8×8 보드에 블록 3개를 끌어다 놓아 가로·세로 줄을 채우면 줄이 사라지는 블록 퍼즐 게임이에요.

홈에서 '게임 시작'을 누르면 블록 몇 개가 깔린 보드에서 바로 시작해요. 아래에 나온 블록 3개를 손가락으로 끌어 빈자리에 놓고, 줄이 가득 차면 "Good!", "Great!" 같은 문구와 함께 줄이 터지며 점수를 얻어요. 줄을 연달아 지우면 콤보가 쌓이고, 5콤보부터는 피버가 켜져 점수가 1.5배가 돼요. 더 놓을 곳이 없으면 게임이 끝나고, 한 판에 한 번 부활할 수 있어요.

'오늘의 챌린지'에서는 매일 모두 같은 블록 순서로 도전하고, '어드벤처'에서는 목표가 있는 스테이지 20개를 깨며 별을 모아요. 게임이 끝나면 점수가 토스 랭킹에 기록되어 친구들과 순위를 비교할 수 있어요. 설정에서 소리·진동·블록 스킨을 바꿀 수 있어요.
